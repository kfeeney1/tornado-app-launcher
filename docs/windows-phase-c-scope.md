# Phase C scope decisions

Included: desktop lifecycle, single-instance behaviour, focus/restore, resizing/window-state recovery, shared navigation/Back behaviour, external navigation, diagnostics visibility, packaging regression and Electron security regression.

Explicitly excluded: tray mode, start-with-Windows, notification framework, updater redesign, telemetry, system/game tuning, Windows-only React screens and duplicate launcher/catalogue implementations. These are not required to establish a coherent desktop product and would distract from practical parity.

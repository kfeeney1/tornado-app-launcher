# Phase C handover

When and only when the Phase C PR is green and merged, inspect the resulting `main` SHA and repository state. If the merge is verified and there is no unresolved automated P0/P1 Phase C defect, Phase D — Packaged Windows Acceptance — may begin under the current scheduling exception.

Phase D must inherit the deferred acceptance register. It may strengthen package/build automation without a local Windows machine, but it cannot declare packaged Windows acceptance complete until the real-machine register has been executed.

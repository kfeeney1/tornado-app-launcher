# Android deferred manual actions

No manual intervention is required to validate the Work Block 2 debug build.

Deferred until the release/publishing block:

- Confirm the permanent Android package/application ID before store publication.
- Create or select the production signing key and protect it outside source control.
- Configure any store account/application listing required for distribution.
- Perform physical-device acceptance where CI/emulator coverage cannot prove native device behaviour.
